    Ajustes

    Estas claves se guardan solo en este navegador (localStorage) y se usan para llamar directamente a las APIs de Google (YouTube y Gemini) desde tu dispositivo. No se suben al repositorio. Usa claves restringidas cuando puedas.

    Créala en Google Cloud Console, habilita "YouTube Data API v3".

    Créala gratis en aistudio.google.com/apikey.

    YouTube no permite leer subtítulos directamente desde el navegador (CORS), así que se usa un proxy intermedio. Puedes cambiarlo por uno propio si lo prefieres.
