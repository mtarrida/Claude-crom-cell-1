    Estas claves se guardan solo en este navegador (localStorage) y se usan para llamar directamente a las APIs de Google y Anthropic desde tu dispositivo. No se suben al repositorio. Usa claves restringidas (por referrer HTTP) cuando puedas.

    YouTube no permite leer subtítulos directamente desde el navegador (CORS), así que se usa un proxy intermedio. Puedes cambiarlo por uno propio si lo prefieres.
